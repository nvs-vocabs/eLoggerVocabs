# eLoggerVocabs
Repository dedicated to discussion related to terms needed to support the logging of scientific activities on-board research vessels

## Request for new terms and ways to contribute
- Requests for a new eLoggerVocabs can be submitted as [regular issues](https://github.com/nvs-vocabs/eLoggerVocabs/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
